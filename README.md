# DEP-Longevity-Evolution
Analysis scripts for the manuscript "Sexual selection and the evolution of sex-specific longevity and aging across the Drosophilidae tree of life" 

Demographic_metrics.qmd - Uses raw mortality data and converts them to species level demographic metrics
DEP_LifespanRscript_0.4 - Uses univariate metrics for fitting evolutionary models and generating Fig. 1
Phylo_analysis_new.qmd - bivariate and multivariate phylogenetic analyses
